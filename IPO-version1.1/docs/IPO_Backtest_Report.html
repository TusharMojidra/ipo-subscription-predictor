Key Insights & Analysis

🟢 What Worked Well

The tier classification (Low/Medium/High) matched the actual subscription tier in 4 out of 5 cases (80%). For Powerica, the model correctly predicted both the Low tier AND the negative listing gain — the closest prediction of all (only ±2.1 pp error). The model correctly identifies struggling IPOs with low subscription demand.

🔴 Where It Struggled

The gain magnitude was often off — averaging ±21.3 percentage points error. The worst case was Shree Ram Twistex: the model predicted +31% gain but the IPO actually lost -32.7% — a 63.8 pp swing. This is because the model's tier classifier saw "High subscription = big gains" as a pattern, but Shree Ram had extreme HNI (220x) and RII (76x) subscription yet still crashed on listing — an anomaly the model hasn't learned.

📐 Why Bagmane Missed the Tier

Bagmane Prime Office had a Total subscription of 16.5x (which is "High" by our definition ≥10x), but the tier classifier predicted "Medium" because it only uses 3 features: issue size (₹3,405 Cr — very large), offer price (₹100), and year. It doesn't see the subscription numbers — those come AFTER bidding closes. The pre-IPO tier model got confused by the unusually large issue size.

🔧 How to Improve

1. More features for the tier classifier — Add sector, company age, profit/loss, and market sentiment. Right now it only uses issue size, price, and year.
2. Non-linear gain model — Switch from Huber regression (linear) to XGBoost or LightGBM for the listing gain prediction, which can capture the non-linear relationship between subscription and gain.
3. Outlier handling — IPOs like Shree Ram Twistex (43x total but -33% gain) are rare outliers. Adding a "normalization factor" or training on more data would help.
4. Time-aware features — Market conditions change month to month. Adding a "recent market momentum" feature would help the model adapt.

📊 Bottom Line

The model is a useful starting point — it correctly identifies the general demand tier 80% of the time, which is significantly better than random guessing (33%). However, the gain prediction needs improvement before it can be used for investment decisions. This is expected for a project with only 648 IPOs of training data and 3 features for classification.
